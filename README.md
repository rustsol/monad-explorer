# 🐒 Monkey Explorer - Monad Testnet Dashboard

## **[View Live Dashboard](https://monkey-explorer.vercel.app)**

## 🌟 Features
- 🐒 **Monkey-themed UI** with professional blockchain explorer functionality
-  **Real-time Monad testnet data**
-  **Dark/Light theme toggle**
- **Interactive block and transaction modals**
- **Smart contract deployment analytics**
- **Token tracking and analysis**
- **Fully responsive design**

## 🛠 Tech Stack
- **Frontend**: React + TypeScript
- **Styling**: Tailwind CSS
- **Charts**: Recharts
- **Blockchain**: Monad Testnet RPC
- **Deployment**: Vercel
